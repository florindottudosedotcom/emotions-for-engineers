How It Works

  1. Select an AI Provider:
    • Cloud AI: Use powerful models from OpenAI, Anthropic, and Google. Requires API keys.
    • WebLLM: Run AI models directly in your browser. No server or keys needed.
    • Ollama: Connect to your local Ollama instance. Only available when running locally.
  2. Enter Presentation Topic: Describe what you want to present about.
  3. AI Generates Visual Slides: The AI creates slides with:
    • Content with bullet points
    • Color schemes and layouts
    • Visual shapes and elements
    • Image suggestions
    • Speaker notes
  4. Preview & Export: Review your presentation and export to PDF, PowerPoint, or HTML.
