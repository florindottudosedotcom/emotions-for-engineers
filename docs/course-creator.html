How to Use This Tool

Welcome to the Universal Course Creator!

This tool helps you generate entire courses using various AI models.

How to Use:
  1. Select an AI Provider:
    • ☁️ Cloud AI: Use powerful models from OpenAI, Anthropic, and Google. You'll need to provide your own API keys in the 'Settings' menu of the Cloud AI page.
    • 🧠 WebLLM: Run a language model directly in your browser. No server or keys needed, but it may be slower.
    • 🖥️ Ollama (Local): Connect to a running Ollama instance on your local machine to use your own models.
  2. Enter a Course Prompt: In the 'Master AI Assistant' section of your chosen creator page, describe the course you want to create. Be as specific as possible!
  3. Generate Course: Click "Generate Entire Course". The AI will first generate a title and description, then proceed to generate content for each chapter.
  4. Review and Edit: Once generated, you can review and edit the content of each chapter in the editor.
  5. Download: When you're happy with the course, click "Generate Course Files" at the bottom to download a .zip file containing all the course materials.
