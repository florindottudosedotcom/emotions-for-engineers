Universal Course Creator

Welcome! This tool helps you generate entire courses using various AI models. Choose your preferred AI provider below to get started.

Cloud AI WebLLM (In-Browser) Ollama (Local) AI Slides Creator

How It Works

  1. Select an AI Provider:
    • Cloud AI: Use powerful models from OpenAI, Anthropic, and Google. You'll need to provide your own API keys.
    • WebLLM: Run a language model directly in your browser. No server or keys needed, but it may be slower and requires a modern browser.
    • Ollama (Local): Connect to a running Ollama instance on your local machine to use your own models. This option is only available when running the tool on your local machine.
  2. Enter a Course Prompt: In the 'Master AI Assistant' section of the creator page, describe the course you want to create. Be as specific as possible!
  3. Generate Course: Click "Generate Entire Course". The AI will first generate a title and description, then proceed to generate content for each chapter.
  4. Review and Edit: Once generated, you can review and edit the content of each chapter in the editor.
  5. Download: When you're happy with the course, click "Generate Course Files" at the bottom to download a .zip file containing all the course materials, ready to be used in a static site generator like MkDocs.
